# 매물 사진·평면도 학습 자료 조사

확인일: 2026-11-09. 현재 프로젝트는 상업 이용 가능한 구성요소만 사용한다. 웹에서 볼 수 있는 자료와 모델 학습에 사용할 권한이 있는 자료는 구분한다.

사용자 요청으로 조사 범위를 국내외 **34개 항목**으로 넓혔다. 최신 비교표는 [사진·평면도 데이터 조사](dataset-survey.md), 출처·조건·판단의 원본 목록은 [dataset-survey.json](dataset-survey.json)에 있다. PanoInfinigen은 하위 구성별 조건, C3는 데이터와 코드 조건, ARKitScenes는 현재의 조건부 상업 조항까지 구분했다. 이 조사는 실제 외부 파일 다운로드·모델 학습 완료를 뜻하지 않는다.

국내 공공기관 경로와 일반 도면 비교 실행 방법은 [공공 평면도 비교](reference-plan.md)에 추가했다. LH 하나로 내집, 제주개발공사의 공공임대주택 평면도 목록, 마이홈 첨부 도면을 확인했다. 실제 외부 매물 사진과 같은 호실의 도면 쌍을 확보해 검증한 건수는 아직 0건이다.

## 정답으로 필요한 정보

사진과 평면도 이미지가 있다고 즉시 학습 정답이 완성되는 것은 아니다. 최소한 같은 집·같은 층·같은 리모델링 상태인지 확인하고, 좌우 반전·확장 여부와 실제 치수 기준을 확인해야 한다. 도면에는 방·복도 다각형과 문이 연결하는 양쪽 공간이 필요하다. 사진에는 소속 공간과 보이는 문 ID를 연결해야 한다.

같은 문이 멀리 보이는 두 사진이 반드시 그 문으로 직접 연결된 두 방에서 찍힌 것은 아니다. 예를 들어 방 A에서 복도 너머 방 B의 문이 보일 수 있다. 데이터에는 **공유된 문 시각 정보**와 **직접 인접한 공간 연결**을 따로 저장한다.

사진을 같은 집 단위로 묶어 학습·검증·평가를 분리해야 한다. 같은 집의 다른 사진을 무작위로 각 분할에 섞으면 이미 본 집을 맞히는 결과가 될 수 있다. 현재 데이터 변환기는 집 ID 중복을 거절하고 집 단위로 분리한다.

## 현재 실제로 사용한 자료

외부 매물 사진·연구 전용 데이터셋·연구 전용 가중치는 사용하지 않았다. `synth_property.py`가 직접 만든 텍스처·여러 공간·출입구·촬영 위치·사진을 사용했다. 원본 사진 입력과 정답 도면은 분리되어 있으며 추론기는 정답 방 윤곽이나 문 ID를 읽지 않는다.

두 합성 집을 사진에서 실제 SfM으로 복원해 `property_graph.py`의 결과와 정답을 비교했다. 평가 때에만 정답 촬영 위치로 좌표와 배율을 정렬한다. 이 수치는 실사진이나 임의의 사이트 도면을 자동으로 정렬해 학습한 성능이 아니다.

`training-pairs` 명령은 권한 메타데이터를 검사하고 사진 쌍의 같은 공간 여부·공유 문·직접 문 연결 정답을 JSONL로 만든다. 사진 및 정답 파일의 SHA-256을 기록한다. 메타데이터 검사는 제3자 자료의 실제 권한을 대신 확인하거나 부여하지 않는다. 생성한 두 집만으로 일반 매물용 신경망 성능을 주장하지 않는다. **신경망 재학습은 수행하지 않았다.**

## GPU와의 관계

현재 특징점 매칭·카메라 복원·공간 관측선·문 연결 후보 계산은 CPU에서 수행한다. Brush의 실사 표현 학습과 뷰어는 GPU를 사용한다. 더 큰 GPU가 사진에 없는 연결 정보를 만들어 주거나 유리벽을 자동으로 구분해 주는 것은 아니다. 새 신경망의 대규모 학습은 별도 작업이며 현재 780M에서 그 학습 성능을 측정하지 않았다.

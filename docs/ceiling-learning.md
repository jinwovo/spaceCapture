# 천장 후보 보조 신경망: 실제 학습과 적용

2026-11-09. `ceiling-mlp-v1`을 처음부터 학습하고 로컬 파이프라인에 연결했다. **입력은 복원된 3D 점군의 기하 특징 21개**다. 방/문 연결 전체나 실내·실외·유리를 사진에서 분류하는 모델은 아직 학습하지 않았다.

모델은 후보가 실제 천장일 근거를 판별한다. 높이 숫자를 생성하거나 도면 정답으로 치수를 덮어쓰지 않는다. 최종 높이는 후보층의 관측점 중앙값이며 근거가 없으면 기존 2.4m를 **가정값**으로 표시한다. 모델 점수는 보정된 정확도 확률이 아니다. 학습·시험은 합성 구조에 한정되며 실제 매물 일반화는 미검증이다.

## 자료와 분할

공식 [ProcTHOR-10K](https://github.com/allenai/procthor-10k)의 Apache-2.0 구조 JSON만 사용했다. 학습 분할 **10,000집 / 53,314,510바이트 / 10.998초**, 시험 분할 **1,000집 / 5,022,093바이트 / 2.682초**를 추가 다운로드했다. 기존 검증 분할 1,000집을 합쳐 원본은 12,000집이다. 고정 버전과 원본 Git LFS SHA-256을 모두 확인했다. 가구/재질 에셋·외부 사전학습 가중치·CUDA 라이브러리는 받지 않았다.

실제 실험에는 다음 부분 집합을 썼다. 구조 유형 `roomSpecId`를 10/3/3개로 나누고, 학습/검증/시험은 각각 공식 train/val/test에서만 가져왔다. 도면은 평행 이동·배율·회전·반전·불필요한 일직선 꼭짓점을 정규화한 지문으로 중복을 제외했다. 집 ID·구조 유형·도면 지문이 분할 사이에 겹치면 학습을 거절한다. 이는 유사 도면을 전부 자동 검출한다는 보장은 아니다.

| 분할 | 집 | 구조 유형 | 점군 변형 | 천장 후보 | 양성 후보 |
|---|---:|---:|---:|---:|---:|
| 학습 | 80 | 10 | 320 | 5,559 | 233 |
| 검증 | 24 | 3 | 96 | 1,010 | 58 |
| 시험 | 20 | 3 | 80 | 1,203 | 56 |

구조 표면에서 직접 점을 샘플링하고 밀도·높이·노이즈를 바꿨다. 천장 전체/부분/미관측, 수직 벽의 수평 무늬층, 가구 상판, 이상점을 포함했다. **실제 사진의 SfM 특징점으로 학습한 자료는 아니다.** 같은 집의 변형 4개는 독립 실제 주택 4개가 아니다. 명세와 집별 지문: `artifacts/ceiling-learning/dataset.json`.

## 실제 학습

- NumPy로 역전파·Adam을 구현한 MLP **21→32→16→1**, 학습 매개변수 **1,249개**.
- CPU 실행, 자료 선택·점군/특징 준비 **25.198초**, 학습·체크포인트/임계값 검증 **0.329초**, 조기 종료 **60회**. 작은 기하 특징 모델이므로 이 PC에서 실행할 수 있었다.
- 검증 손실로 체크포인트를 고르고 검증 자료에서만 임계값 **0.678735**를 선택했다. 시험 결과로 가중치·임계값을 조정하지 않았다.
- 가중치 **6,399바이트**, `models/ceiling-mlp-v1.npz`. 메타데이터·SHA-256·Apache-2.0 LICENSE·변경 고지를 함께 보관했다.
- 추론은 pickle을 사용하지 않고 특징 버전·가중치 크기·유한 값·해시를 검사한다. 활성 모델이 손상되면 천장 높이를 가정하며 이전의 잘못된 검출 방식으로 조용히 돌아가지 않는다.

기하 특징에는 두 규모의 주변점 법선·평면성, 층의 넓이·밀도·두께, 위쪽 관측점 비율 등이 있다. [SciPy cKDTree](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.cKDTree.query.html)와 NumPy만 사용하며 SciPy는 BSD-3-Clause다. 현재 PC에 이미 설치돼 있던 SciPy를 requirements에 명시했다.

## 별도 점군 시험

20개 시험 집에서 만든 80개 점군 변형에 대한 결과다. 천장 관측이 충분한 것은 55개다. 아래 비교는 모두 같은 후보 집합을 사용한다.

| 방식 | 올바른 높이 검출 | 잘못된 높이 검출 | 보류 |
|---|---:|---:|---:|
| 상한을 제거한 기존 넓이·높이층 기준 | 55 | 17 | 8 |
| 고정 법선 규칙 참고값 | 21 | 0 | 59 |
| 학습한 MLP | 55 | 0 | 25 |

MLP가 올바르게 검출한 높이의 평균 오차는 **0.212cm**다. 이 수치는 직접 생성한 노이즈 점군의 결과이며 실사 측정 오차를 뜻하지 않는다. 후보별로는 정밀도 **0.9825**, 재현율 **1.0**이며 후보별 오검출과 장면의 최종 최고 후보 검출은 다른 집계다. 검증 자료에서는 96개 중 **1개를 잘못 확정**했다. 따라서 오검출이 항상 없다고 주장하지 않는다.

고정 법선 규칙은 평균 법선 Y성분 0.75 초과, 위쪽 점 비율 0.08 미만인 참고 비교다. 시험에 맞춰 최적화하지 않았으며 최적의 기하 방법 전체를 대변하지 않는다. 별도 `legacy_test`는 기존 2.5m 상한을 같은 후보에 적용한 모사 비교다.

## 사진 복원으로 확인한 결과

기존 사진 복원 결과 4개와 새로운 시험 집 1개를 검사했다. 추론 함수에는 정답 높이·도면·촬영 위치를 전달하지 않았다. 아래의 정답은 추론 뒤 평가에만 사용했다.

- `procthor-val-0140`: 기존 **3.7477m**(정답 **4.2258m**, −47.81cm)에서 **4.2255m**로 개선됐다. sparse-only는 4.2267m다. 실제 Brush PLY와 합친 점에서도 확인했다. 이 사례는 상한을 제거한 기하 후보만으로도 참 높이가 나온다. 모델만의 단독 높이 개선 효과로 해석하지 않는다.
- `procthor-val-0043`: 잘못된 **3.2963m** 천장 확정을 보류했다. 실제 천장 4.2040m를 찾아낸 것은 아니며 현재 **2.4m 가정**이다.
- `property-rooms-corridor`: 천장 **2.6033m**(정답 2.6m). 기존 넓이/문 연결 점수 유지.
- 원래 `synth`: 관측 근거 부족을 유지하며 **2.4m 가정**(정답 2.5m). 신경망으로 없는 천장을 만들어내지 않았다.
- **새 시험 집 `procthor-test-0186`**: 학습·검증에 사용하지 않은 유형/집 중 현재 사진 변환이 가능한 첫 2~4공간 집을 선택했다. 렌더 사진 **76장→중복 제외 71장→포즈 제외 67장 등록**, SfM 약 **41초**. 기존 **2.7655m**(정답 **3.9374m**) 검출을 보류했다. 천장은 **2.4m 가정**이며 미복원이다.

새 시험 집은 공간 후보 **3/3**, 문 연결 후보 **2/2**, 영역 IoU **0.8681**, 문 중심 평균 오차 **10.43cm**, 폭 평균 오차 **1.33cm**다. 이 방·문 연결 점수는 기존 기하 추론의 결과이며 천장 MLP로 학습한 점수가 아니다. 정답 카메라로 좌표·배율을 맞춘 형태 비교이고, 카메라 정렬 RMSE **51.716cm**의 포즈 오류가 남아 있다. 실측 정확도나 실제 매물 성능으로 해석하지 않는다.

## 앱 적용과 검사

합성 시험과 사진 복원 회귀 결과를 검사한 뒤 **천장 후보 보조 기능**으로 활성화했다. `detect_room`, Brush 이후 `refine_splat_room`, 기존 장면 `inspect`에 적용된다. `inspect`의 높이 갱신은 가로·세로를 유지한다. `ceiling_before_model`에 이전 결과를 보존하고 `room.height_method`, `room.ceiling_analysis`에 모델 근거를 저장한다. UI는 기존 경고 표시를 통해 합성 학습 모델과 미검증 범위를 알린다. 실내/실외·유리 의미 분류 상태와 도면 승인 상태는 기존 미확정을 유지한다.

기존 `synth`는 가로·세로 **+2.8/+3.1cm** 유지. 최종 코드로 영상 전체를 재처리한 `synth-neural-regression`은 **59/59장**, 기록된 단계 합 **52.6초**(프레임 1.9 + SfM 49.3 + 정렬 1.4), 가로·세로 **+2.6/+2.4cm**, 궤적 RMSE **0.16cm**다. 기존 두 집의 IoU **0.9239/0.9092**, 별도 검증점 오차 **0.410/0.608cm**도 유지됐다.

Chrome에서 34,172개 스플랫과 새 높이 **4.23m**, 3D/평면도 전환을 확인했다. 새 시험 집은 공간 3개·연결 2개·양쪽 썸네일 12장과 촬영 위치 이동을 확인했다. JS 예외 **0개**. Python 검사 **51개**, compileall·뷰어 빌드 통과(기존 큰 번들 경고만 있음). 뷰어 소스는 바꾸지 않았다.

## 추론 설정 지문과 활성화 절차 (2026-11-10)

가중치 SHA만으로 검증 기록을 연결하면 같은 가중치에서 임계값을 0.678735→0으로 바꿔도 활성화 검사를 통과했고, 이때 시험 점군의 최종 오검출은 0→17개였다. 이를 막기 위해 다음을 적용했다.

- **추론 설정 지문** `inference_fingerprint`: 모델 ID·가중치 SHA-256·임계값·특징 버전·특징 순서·구조(21→32→16→1)·입력 절단값을 정규화 JSON으로 묶은 SHA-256. 현재 v1 지문은 `724f9b2bd053eba9…`이다.
- 모델 JSON, 학습 보고서(`result.json`), 사진 회귀 보고서(`sfm-regression.json`)와 각 사례의 분석, 활성화 기록(`activation.json`), 설치 모델의 `activation` 항목이 **모두 같은 지문**이어야 한다. 런타임도 지문을 다시 계산하며, 설치 모델은 활성화 기록 지문과도 일치해야 사용한다. 하나라도 다르면 `model_unavailable` → **높이 가정**이다.
- 학습 보고서에 학습·검증·시험 자료 7개 파일(`dataset.json`, `*.npz`, `*-clouds.json`)의 SHA-256을 기록한다. 활성화 때 해시를 재확인하고 현재 가중치·임계값으로 검증/시험 점수를 다시 계산해 보고서와 같은지 확인한다. 시험 최종 오검출이 1개라도 있으면 거절한다.
- 사진 회귀 보고서에 입력 장면의 `points.ply`·`splat.ply` 해시, 사용한 방 상자·카메라 높이, 시험 집 정답 `property.gt.json`과 선택 기록 해시를 남긴다. 활성화 때 현재 파일과 다르면 회귀를 다시 실행해야 한다.
- 메타데이터가 없는데 가중치가 남아 있거나, 메타데이터가 손상되거나, 활성화 기록이 없으면 기존 높이층 방식으로 돌아가지 않고 높이를 가정한다. 기존 방식은 `enabled_by_default=false`로 **의도적으로 비활성화**했거나 모델 파일이 아예 없을 때만 쓴다.
- `report-ceiling-learning.py`는 학습 당시의 모델 해시·임계값을 덮어쓰지 않는다. 실행 폴더 가중치와 다르면 실패한다.
- **재학습은 새 실행 폴더**(`artifacts/ceiling-learning/runs/<시각>/`)에 자료·`model/`·보고서를 저장하고 `models/`를 건드리지 않는다. 검사를 모두 통과한 뒤에만 `activate`가 이전 설치본을 `artifacts/ceiling-learning/previous-models/`에 백업하고 원자적으로 교체한다. 기존 v1 결과는 `artifacts/ceiling-learning/` 자체를 실행 폴더로 옮겼다(`model/` 추가, 가중치·임계값 변경 없음).
- 실제 확인: `--reuse-data`로 재학습한 `runs/20261110-090439`은 학습 약 1초, 가중치 SHA·지문이 v1과 **비트 단위로 동일**, 시험 55/0/25 동일. 회귀·활성화 검사(`--check-only`) 통과, 설치는 하지 않았다. 학습 전후 `models/` 4개 파일 해시 불변.
- 회귀 시험 `tests/test_ceiling_records.py`(17개): 임계값 0 변경 거절(메타데이터만/보고서까지 수정 모두), 다른 설정의 사진 회귀·시험 자료 변경·입력 장면/정답 해시 변경 거절, 실패한 활성화 시 설치본 불변, 보고서 모델 해시 보존, 재학습이 설치본을 바꾸지 않음, 메타데이터 누락·손상·임계값 변경·활성화 기록 누락 시 높이 가정.

### procthor-test-0186 카메라 정렬 RMSE 51.716cm 조사

천장 모델과 무관한 SfM 포즈 오류였다. 사진별 카메라에서 관측점이 매우 적은 두 장(6점·초점비 2.353, 50점·0.458, 나머지 중앙값 581점·0.617)의 잘못된 포즈를 BA가 초점거리로 흡수했다. 관측이 매우 적고 초점비가 크게 다른 포즈, 그리고 관측점 12개 미만 포즈를 정답 없이 제외하도록 `sfm.py`를 고쳤다. 최종 재처리 RMSE **1.797cm**, 문 중심 **6.58cm**, IoU **0.8700**. 천장은 여전히 후보가 없어 **2.4m 가정**이며 정답 3.9374m는 미복원이다. 기록: `pose-rmse-investigation.json`.

재실행:

```powershell

.\.venv\Scripts\python.exe -X utf8 tools/fetch-procthor.py --split test
.\.venv\Scripts\python.exe -X utf8 tools/train-ceiling-model.py                # 새 runs/<시각>/ 에 저장 (--reuse-data 로 특징 재사용)

.\.venv\Scripts\python.exe -X utf8 tools/activate-ceiling-model.py --run artifacts/ceiling-learning/runs/<시각>

.\.venv\Scripts\python.exe -m spacecapture inspect procthor-val-0140
```
